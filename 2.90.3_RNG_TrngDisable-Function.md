# 2.90.3 RNG_TrngDisable Function

## C

```C
void RNG_TrngDisable (void);
```

## Summary

Disables the TRNG block inside the RNG peripheral


## Description

Disables the operation of TRNG block inside the RNG peripheral.
This also resets RNGCNT register which holds the number of valid bits
in the RNGSEEDx registers.


## Precondition

RNG_Initialize must have been called before using this function.


## Parameters

None.


## Returns

None.


## Example

```C
RNG_TrngDisable();
```

None.
