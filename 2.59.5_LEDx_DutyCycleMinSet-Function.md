# 2.59.5 LEDx_DutyCycleMinSet Function

## C

```C
/* x = LED peripheral instance number */

void LEDx_DutyCycleMinSet(uint8_t min)
```

## Summary

Specifies the minimum duty cycle value.


## Description

When the current duty cycle is less than or equal to the min value the breathing
                apparatus holds the current duty cycle for the period specified by the field LD in
                register LED_DELAY


## Precondition

None


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| min | Minimum value of the duty cycle in LED breathing
                                mode |
