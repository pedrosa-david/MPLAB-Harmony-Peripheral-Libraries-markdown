# 2.103.56 SERCOMx_SPI_WriteBufferSizeGet Function

## C

```C
/* x = SERCOM instance number */

/* SPI slave mode */

size_t SERCOMx_SPI_WriteBufferSizeGet(void)
```

## Summary

Returns the size of the PLIB's internal transmit buffer


## Description

This function returns the size of the SPI PLIB's internal transmit buffer. The transmit
        buffer size will be the same as configured in MCC.


## Precondition

None


## Parameters

None


## Returns

size_t - Size of the PLIB's internal transmit buffer


## Example

```C
size_t txBufferSize;

txBufferSize = SERCOM0_SPI_WriteBufferSizeGet();
```

## Remarks

None.
