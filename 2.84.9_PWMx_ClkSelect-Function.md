# 2.84.9 PWMx_ClkSelect Function

## C

```C
/* x = PWM instance number */

void PWMx_ClkSelect (PWM_CLK_SEL pwmClk)
```

## Summary

Selects the clock source for the PWM peripheral


## Description

Selects the clock source for the PWM peripheral. The source clock can be selected
                between 100 KHz slow clock and 48 MHz fast clock.


## Precondition

None


## Parameters
