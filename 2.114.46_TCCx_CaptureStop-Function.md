# 2.114.46 TCCx_CaptureStop Function

## C

```C
/* x = TCC instance number */
void TCCx_CaptureStop ( void );
```

## Summary

Stops the timer for given TCC instance.


## Description

This function stops the clock and thus counter.


## Precondition

TCCx_CaptureInitialize() function must have been called first.


## Parameters

None.


## Returns

None.
