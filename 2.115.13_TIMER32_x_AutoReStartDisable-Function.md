# 2.115.13 TIMER32_x_AutoReStartDisable Function

## C

```C
/* x = Timer32 instance number */

void TIMER32_x_AutoReStartDisable(void)
```

## Summary

Disable auto re-start of the timer


## Description

Disable auto re-start of the timer. The counter will simply enter a done state and
                wait for further control inputs.


## Precondition

TIMER32_x_Initialize() function must have been called


## Parameters

None


## Returns

None


## Example

```C
TIMER32_0_AutoReStartDisable();
```
