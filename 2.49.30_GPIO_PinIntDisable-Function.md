# 2.49.30 GPIO_PinIntDisable Function

## C

```C
void GPIO_PinIntDisable(GPIO_PIN pin);
```

## Summary

Disables IO interrupt on selected IO pin.


## Description

This function disables IO interrupt on selected IO pin.


## Precondition

Corresponding pin must be configured in interrupt mode in MCC Pin Manager.


GPIO_Initialize() must have been called.


- Corresponding pin must be configured in interrupt mode in MCC Pin Manager.
