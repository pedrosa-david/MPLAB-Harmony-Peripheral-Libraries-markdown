# 2.125.16 WDT_TimeoutActionSet Function

## C

```C
void WDT_TimeoutActionSet(WDT_TIMEOUT_ACTION action)
```

## Summary

Selects the action to be taken when WDT expires


## Description

Selects the action to be taken when WDT expires. The API can be used to either
                generate interrupt or reset the system when WDT expires.


## Precondition

None


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| action | WDT timeout action of Enum type
                                WDT_TIMEOUT_ACTION |


| Param | Description |
| --- | --- |
| action | WDT timeout action of Enum type
                                WDT_TIMEOUT_ACTION |


## Returns

None


## Example

```C
WDT_TimeoutActionSet(WDT_TIMEOUT_ACTION_RESET);
```

## Remarks

This API is only available when the interrupt mode is enabled in the MCC. Hence it
                can be used at run time to change the WDT action from generating an interrupt to
                resetting the system.
