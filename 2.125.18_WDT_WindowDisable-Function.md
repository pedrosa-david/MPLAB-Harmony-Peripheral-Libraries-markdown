# 2.125.18 WDT_WindowDisable Function

## C

```C
void WDT_WindowDisable( void )
```

## Summary

Disables the WDT window mode.


## Description

This function is used to disable window mode operations.


## Preconditions

This API is generated to disable the Window mode in firmware if the window mode is disabled
        by setting WINDIS fuse bit to OFF/NORMAL in MCC device configuration.


## Parameters

None.


## Returns

None.


## Example

```C
WDT_WindowDisable();
```

None.
