# 3.22.14 Low Power Modes (Power)

PIC32 devices offer various methods and modes that allow the user to
balance power consumption with device performance. Power plib provides
interface to get into such low power modes.


## Using The Library

To enter into any of the power saving mode, user can call the API
POWER_LowPowerModeEnter.


## Library Interface

Low Power Modes peripheral library provides the following interfaces:
