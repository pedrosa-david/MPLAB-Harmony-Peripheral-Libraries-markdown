# 3.25.11 External Bus Interface (EBI)

The External Bus Interface (EBI) module provides a high-speed,
convenient way to interface external parallel memory devices to the
PIC32MZ EF family device.


With the EBI module, it is possible to connect asynchronous SRAM and
NOR Flash devices, as well as non-memory devices such as camera sensors
and LCDs.


## Using The Library

```C
EBI_Initialize();
```
