# 3.44.2 Clock Generator (CLOCK)

The Clock system generates and distributes the clock for the processor and peripherals.


## Using The Library

The Clock peripheral library initializes the clock system as configured by the user in the MCC
                Clock configurator. It can be accessed via the "Tools" drop down of the MPLAB Code
                Configurator menu bar.


## Library Interface

Clock Generator peripheral library provides the following interfaces:


Functions


| Name | Description |
| --- | --- |
| CLOCK_Initialize | Initializes the clock for system and peripherals |
