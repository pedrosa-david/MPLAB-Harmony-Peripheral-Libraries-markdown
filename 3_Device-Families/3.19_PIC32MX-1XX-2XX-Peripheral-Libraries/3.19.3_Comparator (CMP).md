# 3.19.3 Comparator (CMP)

The CMP peripheral consists of two comparators (CMP1 and CMP2). Inputs
for these comparators can be selected from various sources such as I/O
pins, CVR and internal 1.2 volts reference (IVREF).


## Using The Library

CMP Peripheral library provides API's that can be used to perform below
functionalities on the CMP peripheral.


Initialize the CMP.


Turn on and turn off the individual comparators inside the CMP
peripheral.


Register callback function for the two comparators inside the CMP
peripheral.


Get the status of individual comparator output


- Initialize the CMP.
- Turn on and turn off the individual comparators inside the CMP
peripheral.
- Register callback function for the two comparators inside the CMP
peripheral.
- Get the status of individual comparator output
