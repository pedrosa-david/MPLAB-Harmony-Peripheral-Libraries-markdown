# 3.31.9 AHB Bus Matrix (MATRIX)

The MATRIX provides one decoder for every host interface. The decoder offers each host
      several memory mappings.


Each memory area can be assigned to several clients. Booting at the same address while using
      different clients (i.e. external RAM, internal ROM or internal Flash, etc.) becomes
      possible.


## Using The Library

The MATRIX plib does not allow any user configurations.
