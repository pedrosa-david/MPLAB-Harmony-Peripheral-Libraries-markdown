# 3.11.19.8 SEFC_PageErase Function

## C

```C
bool SEFC_PageErase( uint32_t address)
```

## Summary

Erases a Page in the FLASH.


## Description

Depending on which flash panel is mapped at the given address, it calls the associated SEFC
        flash controller instance and erases the corresponding page.


## Precondition

Validate if SEFCx controller is ready to accept new request by calling SEFC_IsBusy()


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| address | FLASH address to be Erased |


| Param | Description |
| --- | --- |
| address | FLASH address to be Erased |


## Returns

Always returns true.


## Example

```C
SEFC_PageErase(0x500000);

while(SEFC_IsBusy(0x500000));
```

## Remarks

Application needs to poll for busy bit or wait for callback to be called before sending next request.
