# 3.11.19.14 SEFC_SectorErase Function

## C

```C
bool SEFC_SectorErase( uint32_t address)
```

## Summary

Erases a Sector in the FLASH.

## Description

This function determines the flash panel for the given address by calling
        SEFCFlashPa≠lGetSEFC_FlashPanelGet and then erases the corresponding sector (collection of pages).

## Precondition

Validate if SEFCx controller is ready to accept new request by calling SEFC_IsBusy()

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| address | FLASH address to be Erased |

| Param | Description |
| --- | --- |
| address | FLASH address to be Erased |

## Returns

Always returns true.

## Example

```C
SEFC_SectorErase(0x500000);

while(SEFC_IsBusy());
```

## Remarks

Application needs to poll for busy bit or wait for callback to be called before sending next request.
