# 3.11.19.3 SEFC_FlashPanelGet Function

## C

```C
SEFC_FLASH_PANEL SEFC_FlashPanelGet(uint32_t address)
```

## Summary

Identify the flash panel (SEFC0 or SEFC1) for the given address based on the GPNVM bit.

## Description

This function identifies the flash panel by checking the GPNVM bit and returns
        SEFC_FLASH_PANEL0 or SEFC_FLASH_PANEL1 depending on which flash panel is currently mapped at
        the given address.

## Precondition

None

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| address | FLASH panel to identify. |

| Param | Description |
| --- | --- |
| address | FLASH panel to identify. |

## Returns

SEFC_FLASH_PANEL - SEFC controller flash panel.

## Example

```C
SEFC_FLASH_PANEL flash_panel = SEFC_FlashPanelGet(0x500000);
```
