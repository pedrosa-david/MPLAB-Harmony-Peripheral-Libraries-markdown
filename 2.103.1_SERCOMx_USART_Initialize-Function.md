# 2.103.1 SERCOMx_USART_Initialize Function

## C

```C
/* x = SERCOM instance number */

/* Blocking, non-blocking and ring buffer mode */

void SERCOMx_USART_Initialize( void )
```

## Summary

Initializes given instance of the USART peripheral.


## Description

This function initializes the given instance of the USART peripheral as configured by the
        user from MCC.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
SERCOM0_USART_Initialize();
```

## Remarks

Stops the USART if it was already running and reinitializes it.
