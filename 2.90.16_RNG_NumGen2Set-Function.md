# 2.90.16 RNG_NumGen2Set Function

## C

```C
void RNG_NumGen2Set (uint32_t numgen);
```

## Summary

Loads a value into the RNGNUMGEN2 register.


## Description

This function can be used to set an initial seed value for the PRNG.
When the PRNG operation is finished, RNGNUMGEN2 register contains
the MSB 32-bits of the current random number in the PRNG.


## Precondition

None.


## Parameters

Value to be loaded into RNGNUMGEN2 register.


## Returns

None.


## Example

```C
RNG_NumGen2Set(0x0d0e0f10);
```

## Remarks

None.
