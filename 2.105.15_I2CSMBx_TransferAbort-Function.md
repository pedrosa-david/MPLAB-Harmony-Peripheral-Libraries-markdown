# 2.105.15 I2CSMBx_TransferAbort Function

## C

```C
/* x = I2C SMBUS peripheral instance number */

/* I2C master mode */
bool I2CSMBx_TransferAbort(void)
```

## Summary

Aborts an ongoing transfer


## Description

Aborts an ongoing transfer by sending a STOP bit if write was in progress and sending
                a NAK if read was in progress


## Precondition

I2CSMBx_Initialize must have been called for the associated I2C instance and a
                transfer should be in progress


## Parameters

None


## Returns

None


## Example

```C
I2CSMB0_TransferAbort();
```

None
