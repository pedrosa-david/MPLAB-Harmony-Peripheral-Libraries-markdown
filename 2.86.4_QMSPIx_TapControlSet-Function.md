# 2.86.4 QMSPIx_TapControlSet Function

## C

```C
// x - Instance of the QMSPI peripheral

void QMSPIx_TapControlSet(uint16_t tap_vl, uint32_t tap_ctrl);
```

## Summary

Set control tap adjustment to QMSPI peripheral.


## Description

Set control tap adjustment to QMSPI peripheral. This is used to adjust the auto-H/W trim if
        needed.


## Precondition

QMSPI must first be initialized using QMSPIx_Initialize().


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| tap_vl | Tap value to adjust the auto-H/W trim. |
| tap_ctrl | Select the tap point for signals, these signals control the
                interface characteristics |
