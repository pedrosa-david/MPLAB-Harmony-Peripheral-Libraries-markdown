# 2.62.16 MCPWM_ChannelPinsOverrideEnable Function

## C

```C
void MCPWM_ChannelPinsOverrideEnable (MCPWM_CH_NUM channel)
```

## Summary

Enables PWM output pins override function


## Description

This function enables override function for PWM output pins PWMH and PWML.
When override is enabled, PWM generation logic does not control the PWMH and PWML states.


## Precondition

MCPWM_Initialize() must have been called first for the associated instance.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| channel | MCPWM channel number |


| Param | Description |
| --- | --- |

## Returns

None.

MCPWM_Initialize();
MCPWM_ChannelPinsOverrideEnable(MCPWM_CH_0);
