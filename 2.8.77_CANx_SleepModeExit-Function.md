# 2.8.77 CANx_SleepModeExit Function

## C

```C
void CANx_SleepModeExit(void) // x - Instance of the CAN peripheral
```

## Summary

Exits CAN peripheral from sleep mode (clock stop request).


## Precondition

CANx_Initialize, CANx_MessageRAMConfigSet and CANx_SleepModeEnter must have been called for the associated CAN instance.
