# 2.84.29 PWM_CALLBACK Typedef

## C

```C
typedef void (*PWM_CALLBACK)( uint32_t status, uintptr_t context );
```

## Summary

Defines the data type and function signature for the PWM peripheral callback function.


## Description

This data type defines the function signature for the PWM peripheal
callback function. The library will call back the client's
function with this signature from the interrupt context.
