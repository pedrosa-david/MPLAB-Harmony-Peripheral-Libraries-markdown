# 2.61.41 MCAN_ERROR_LEC_NO_CHANGE Macro

## C

```C
#define MCAN_ERROR_LEC_NO_CHANGE 0x7U
```

## Summary

MCAN Error LEC_NO_CHANGE


## Description

Any read access to the Protocol Status Register re-initializes the LEC to ‘7’. When
the LEC shows value ‘7’, no CAN bus event was detected since the last processor
read access to the Protocol Status Register.
