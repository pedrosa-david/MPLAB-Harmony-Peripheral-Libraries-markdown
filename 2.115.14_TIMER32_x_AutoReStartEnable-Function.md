# 2.115.14 TIMER32_x_AutoReStartEnable Function

## C

```C
/* x = Timer32 instance number */

void TIMER32_x_AutoReStartEnable(void)
```

## Summary

Enable auto re-start of the timer


## Description

The counter will automatically restart the count, using the contents of the Timer
                Preload Register to load the Timer Count Register


## Precondition

TIMER32_x_Initialize() function must have been called


## Parameters

None


## Returns

None


## Example

```C
TIMER32_0_AutoReStartEnable();
```
