# 2.110.4 SUPC_SetOutputPin Function

## C

```C
void SUPC_SetOutputPin( SUPC_OUTPIN pin );
```

## Summary

Sets a specific output pin (OUTx) to logic HIGH.


## Description

There are two pins controlled by the SUPC. This API helps to drive
a logic HIGH on a given OUTx pin.


## Precondition

None.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| pin | Identifies the output pin to be set |
