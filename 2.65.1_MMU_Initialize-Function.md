# 2.65.1 MMU_Initialize Function

## C

```C
void MMU_Initialize(void)
```

## Summary

Initialize and enable MMU.


## Description

Initialize the MMU with a flat address map (e.g. physical and virtual addresses are the same) and enable MMU and caches.
