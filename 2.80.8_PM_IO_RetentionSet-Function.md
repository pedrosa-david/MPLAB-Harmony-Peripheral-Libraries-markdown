# 2.80.8 PM_IO_RetentionSet Function

## C

```C
void PM_IO_RetentionSet( void );
```

## Summary

Turns on I/O retention when exiting HIBERNATE or BACKUP mode.


## Description

If this function is called before entering HIBERNATE or BACKUP mode,
then while exiting the sleep, the configuration of the I/O lines is
retained until PM_IO_RetentionClear() is called.
Refer the bit description of PM->CTRLA.IORET in datasheet before using
this function. When IORET is enabled, SWD access to the device will not be
available after waking up from Hibernate/Backup sleep until the bit is
cleared by the application.


## Precondition

None.

None.

None.

PM_IO_RetentionSet();
