# 2.45.44 FLEXCOMx_SPI_WriteBufferSizeGet Function

## C

```C
/* x = FLEXCOM instance number */

/* SPI slave mode */

size_t FLEXCOMx_SPI_WriteBufferSizeGet(void)
```

## Summary

Returns the size of the PLIB's internal transmit buffer


## Description

This function returns the size of the SPI PLIB's internal transmit buffer. The transmit
        buffer size will be the same as configured in MCC.


## Precondition

None


## Parameters

None


## Returns

size_t - Size of the PLIB's internal transmit buffer


## Example

```C
size_t txBufferSize;

txBufferSize = FLEXCOM0_SPI_WriteBufferSizeGet();
```

## Remarks

None.
