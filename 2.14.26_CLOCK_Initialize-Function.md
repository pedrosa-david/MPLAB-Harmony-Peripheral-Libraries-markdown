# 2.14.26 CLOCK_Initialize Function

## C

```C
void CLOCK_Initialize (void);
```

## Summary

Initializes clock system.


## Description

This function initializes complete clock system as per MCC configuration.


## Preconditions

MCC GUI should be configured with the right values. Incorrect configuration of the Clock
        will result in incorrect peripheral behavior or a non functional device.


## Returns

None.


## Example

```C
CLOCK_Initialize();
```
