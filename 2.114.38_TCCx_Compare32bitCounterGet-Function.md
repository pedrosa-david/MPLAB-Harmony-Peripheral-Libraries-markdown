# 2.114.38 TCCx_Compare32bitCounterGet Function

## C

```C
/* x = TCC instance number */
uint32_t TCCx_Compare32bitCounterGet( void );
```

## Summary

Reads the timer current count value.


## Description

This function reads the timer count value.


## Precondition

TCCx_CompareInitialize() function must have been called first.


## Parameters

## Returns

Timer's current count value.


## Example

```C
uint32_t counter = 0;
TCC0_CompareInitialize();
TCC0_CompareStart();
counter = TCC0_Compare32bitCounterGet();
```

## Remarks

The caller must know the number of significant bytes of timer. Period value is
            right-aligned
