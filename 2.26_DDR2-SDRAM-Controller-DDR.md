# 2.26 DDR2 SDRAM Controller (DDR)

The DDR2 SDRAM Controller implements the controls for an external
memory bus interface using the Dual Data Rate version 2 (DDR2) protocol
and electrical interface that adheres to the JEDEC Standard JESD79-2F
(Nov. 2009).


The component consists of a DDR2 SDRAM Controller Core with
configurable options and a DDR2 Physical Interface.
