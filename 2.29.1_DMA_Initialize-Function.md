# 2.29.1 DMA_Initialize Function

## C

```C
void DMA_Initialize( void )
```

## Summary

Initializes the DMA controller of the device.


## Description

This function initializes the DMA controller of the device as configured by the user from
        within the DMA manager of MCC.


## Precondition

The DMA module clock requirements should have been configured in the MCC Clock Manager
        utility.


## Parameters

None.


## Returns

None.


## Example

```C
DMA_Initialize();
```

None
