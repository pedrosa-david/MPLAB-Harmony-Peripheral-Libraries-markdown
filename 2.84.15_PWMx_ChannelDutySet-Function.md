# 2.84.15 PWMx_ChannelDutySet Function

## C

```C
/* x = PWM instance number */

void PWMx_ChannelDutySet(PWM_CHANNEL_NUM channel, uint32_t duty);

void PWMx_ChannelDutySet(PWM_CHANNEL_NUM channel, uint16_t duty);
```

## Summary

Writes the duty cycle value of given PWM channel


## Description

This function writes the duty cycle value in double buffer register. Update to the
actual duty cycle register happens at the next period border.


## Precondition

PWMx_Initialize() function must have been called first for the associated instance. And associated channel must be running.


## Parameters

### Parameters

| channel | PWM channel number |
