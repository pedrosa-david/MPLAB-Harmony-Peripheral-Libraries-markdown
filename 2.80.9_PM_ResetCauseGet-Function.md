# 2.80.9 PM_ResetCauseGet Function

## C

```C
PM_RESET_CAUSE PM_ResetCauseGet (void);
```

## Summary

Reports the cause of the last reset


## Description

This function is used to know the cause of the last reset.


## Precondition

None.


## Parameters

None.


## Returns

PM_RESET_CAUSE - Identifies cause of reset, either General, Backup,
Watchdog, Software or User Reset
