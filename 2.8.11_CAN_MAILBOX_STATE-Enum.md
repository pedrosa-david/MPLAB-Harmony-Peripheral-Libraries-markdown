# 2.8.11 CAN_MAILBOX_STATE Enum

```C
typedef enum
{
    CAN_MAILBOX_READY = 0,
    CAN_MAILBOX_BUSY
} CAN_MAILBOX_STATE;
```

## Summary

CAN Mailbox State.


## Description

This data type defines the CAN Mailbox State. CAN_MAILBOX_READY - Mailbox is available for Tx/Rx transfer request. CAN_MAILBOX_BUSY - Mailbox is not available for Tx/Rx transfer request as Mailbox is in busy state due to previous transfer request.
