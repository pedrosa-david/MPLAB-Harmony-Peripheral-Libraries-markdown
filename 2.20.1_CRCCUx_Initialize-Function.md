# 2.20.1 CRCCUx_Initialize Function

## C

```C
void CRCCUx_Initialize( void ); // x - Instance of the CRCCU peripheral
```

## Summary

Initializes given instance of CRCCU peripheral.


## Description

This function initializes given instance of CRCCU peripheral of the device with the values
        configured in MCC GUI. Once the peripheral is initialized, peripheral can be used for CRC
        Calculation.


## Precondition

MCC GUI should be configured with the right values.


## Parameters

None.


## Returns

None.


## Example

```C
CRCCU_Initialize();
```

## Remarks

This function must be called before any other CRCCU function is called.  This function should only be called once during system initialization.
