# 2.95 RTOS Timer

The RTOS Timer is a low-power, 32-bit timer designed to operate on the 32kHz oscillator which
      is always available during all chip sleep states. This allows firmware the option to sleep the
      processor and wake after a programmed amount of time. The timer may be used as a one-shot
      timer or a continuous timer. When the timer transitions to 0 it is capable of generating a
      wake-capable interrupt to the embedded controller. This timer may be halted during debug by
      hardware or via a software control bit.


## Using the Library

```C
void rtos_tmr_callback(uintptr_t context)
{
    LED0_Toggle();
}

int main ( void )
{
    /* Initialize all modules */
    SYS_Initialize ( NULL );
    
    RTOSTimer_CallbackRegister(rtos_tmr_callback, 0);
    
    RTOSTimer_Start();

    while ( true )
    {
        /* Maintain state machines of all polled MPLAB Harmony modules. */
        SYS_Tasks ( );
    }

    /* Execution should not come here during normal operation */

    return ( EXIT_FAILURE );
}
```
