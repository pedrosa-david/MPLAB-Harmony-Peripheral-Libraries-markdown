# 2.88.2 RAM_Write Function

## Summary

Write length number of bytes to a given address in RAM.


## Description

Write length number of bytes to a given address in RAM from the user buffer.


## Precondition

None


## Parameters

|-----------|-------------|
| data | pointer to user data buffer |
