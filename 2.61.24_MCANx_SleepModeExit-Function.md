# 2.61.24 MCANx_SleepModeExit Function

## C

```C
void MCANx_SleepModeExit(void) // x - Instance of the MCAN peripheral
```

## Summary

Exits MCAN peripheral from sleep mode (clock stop request).


## Precondition

MCANx_Initialize, MCANx_MessageRAMConfigSet and MCANx_SleepModeEnter must have been called for the associated MCAN instance.


## Parameters

None.


## Returns

None.


## Example

```C
MCAN0_SleepModeExit();
```
