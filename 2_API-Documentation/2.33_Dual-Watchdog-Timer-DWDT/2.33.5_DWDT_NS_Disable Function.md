# 2.33.5 DWDT_NS_Disable Function

## C

```C
void DWDT_NS_Disable(void)
```

## Summary

Disables the never secure watchdog timer

## Description

This function disables the never secure watchdog timer (NSWDT).
NSWDT can only be disabled, if the configurations are not locked during
initialization.

## Precondition

DWT_Initialize must have been called with lock disabled.

## Parameters

None

## Returns

None.

## Example

```C
DWDT_Initialize();

// Clears the watchdog timer so that it restarts the count
DWDT_NS_Disable();
```
