# 2.93.40 RTC_Timer16InterruptEnable Function

## C

```C
void RTC_Timer16InterruptEnable (RTC_TIMER16_INT_MASK interrupt)
```

## Summary

Enable Selected RTC interrupt

## Description

This function allows the application to enable period match, compare match
and periodic event interrupt

## Precondition

RTC_Initialize must have been called for the associated RTC instance. The Interrupt option
        in MCC should have been enabled. The RTC peripheral should have been configured for 16-bit
        timer counter operation. A valid event handling callback function should have been
        registered by calling the RTC_Timer16CallbackRegister() function.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| InterruptMask | Specifies interrupt source to be enabled |

| --- | --- |
| InterruptMask | Specifies interrupt source to be enabled |

## Returns

None.

## Example

```C
RTC_Timer16InterruptEnable(RTC_TIMER16_INT_MASK_PERIOD_MATCH);
```
