# 2.93.46 RTC_Timer16TimeStampGet Function

## C

```C
uint16_t RTC_Timer16TimeStampGet( void )
```

## Summary

Get the Time stamp of Tamper Detection.

## Description

This function is used to get the 32-bit counter Value at
which the tamper Detection took place.

## Precondition

Tamper channels must be configured properly using MCC.

## Parameters

None.

## Returns

16-bit counter Value.

## Example

```C
uint16_t tamperTime = RTC_Timer16TimeStampGet();
```
