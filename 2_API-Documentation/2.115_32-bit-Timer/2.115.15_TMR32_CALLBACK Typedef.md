# 2.115.15 TMR32_CALLBACK Typedef

## C

```C
typedef void (*TMR32_CALLBACK)(uintptr_t context);
```

## Summary

Defines the data type and function signature for the timer peripheral callback
                function.

## Description

This data type defines the function signature for the timer peripheral callback
                function. The timer peripheral will call back the client's function with this
                signature when the timer expires.

## Precondition

TIMER32_x_Initialize() function must have been called first.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| context | A value (usually a pointer) which is passed (unused)
                                into the function identified by the callback parameter |
