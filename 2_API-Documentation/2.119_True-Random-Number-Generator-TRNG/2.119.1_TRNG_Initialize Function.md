# 2.119.1 TRNG_Initialize Function

## C

```C
void TRNG_Initialize (void);
```

## Summary

Initializes TRNG module of the device


## Description

This function initializes TRNG module of the device with the values configured in MCC
        GUI.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
TRNG_Initialize();
```

## Remarks

This function must be called only once and before any other TRNG function is called. This is taken care in initialization.c.
