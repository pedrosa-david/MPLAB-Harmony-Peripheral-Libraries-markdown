# 2.46.1 FREQM_Initialize Function

## C

```C
void FREQM_Initialize(void)
```

## Summary

Initializes FREQM module.

## Description

This function initializes FREQM module with the values configured in MCC GUI. Once the
        peripheral is initialized, measurement APIs can be called to perform frequency
        measurement.

## Precondition

MCC GUI should be configured with the right values.

## Parameters

None.

## Returns

None.

## Example

```C
FREQM_Initialize();
```

## Remarks

This function must be called before any other FREQM function is called.
