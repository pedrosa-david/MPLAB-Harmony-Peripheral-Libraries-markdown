# 2.120.8 TSENS_ConversionResultGet Function

## C

```C
uint32_t TSENS_ConversionResultGet(void);
```

## Summary

Returns the measured temperature value


## Description

This function returns the last measured temperature value.


## Precondition

TSENS_Initialize() function must have been called first for the associated instance


## Parameters

## Returns

result - 24-bit last measured temperature value


## Example

```C
uint32_t result;
TSENS_Initialize();
TSENS_Enable();
TSENS_ConversionStart();
while(!TSENS_ConversionStatusGet());
result = TSENS_COnversionResultGet();
```

## Remarks

This function can be called from interrupt or by polling the status when result is
            available. The result is 24-bit value in two's complement format.
