# 2.120.12 TSENS_WindowMonitorStatusGet Function

## C

```C
bool TSENS_WindowMonitorStatusGet(void);
```

## Summary

Read the status of the window monitor comparison

## Description

This function returns the status of the comparison of measured temperature and the
            predefined window threshold values

## Precondition

TSENS_Initialize() function must have been called first for the associated instance

## Parameters

## Returns

true - when measured temperature satisfies the window mode and threshold values

false - when measured temperature is out of range

## Example

```C
bool status = false;
TSENS_Initialize();
TSENS_Enable();
TSENS_ConversionStart();
status = TSENS_WindowMonitorStatusGet();
```

## Remarks

This function is used to poll the window comparison status. This should be called after
            conversion is started.
