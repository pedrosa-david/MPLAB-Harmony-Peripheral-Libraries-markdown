# 2.66.1 MPU_Initialize Function

## C

```C
void MPU_Initialize(void)
```

## Summary

Initializes MPU


## Description

Initializes MPU based on the MPU configuration done in MCC


## Precondition

MPU must be configured correctly in the MCC GUI


## Parameters

None


## Returns

None


## Example

```C
MPU_Initialize();
```

## Remarks

MPU_Initialize() will be called from the C startup code, before the main is called.
