# 2.99.17 SDHCx_ModuleInit Function

## C

```C
/* x = SDHC instance number (x is applicable only on devices with more than one instances of SDHC) */

void SDHCx_ModuleInit ( void )
```

## Summary

Initializes the SDHC peripheral.

## Description

This function initializes the SDHC peripheral. The SDHC peripheral is
initialized in 1 bit mode and the SDHC clock is set to 400 kHz. This function
may be called at run time to re-initialize the peripheral to the initial
state.

## Precondition

None.

## Parameters

None.

## Returns

None.

## Example
