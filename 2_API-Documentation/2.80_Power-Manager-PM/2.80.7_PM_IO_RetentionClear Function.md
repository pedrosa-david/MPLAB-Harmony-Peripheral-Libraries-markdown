# 2.80.7 PM_IO_RetentionClear Function

## C

```C
void PM_IO_RetentionClear( void );
```

## Summary

Turns off I/O retention. To be called after exiting HIBERNATE or BACKUP mode.


## Description

If PM_IO_RetentionSet function is called before entering HIBERNATE
or BACKUP mode, then while exiting the sleep, the configuration of
the I/O lines is retained until PM_IO_RetentionClear() is called.
Refer the bit description of PM->CTRLA.IORET in datasheet before using
this function. When IORET is enabled, SWD access to the device will not be
available after waking up from Hibernate/Backup sleep until the bit is
cleared by the application.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
PM_IO_RetentionClear();
```
