# 2.3.78 ADC_GLOBAL_INT_CRRDY1 Macro

## C

```C
#define ADC_GLOBAL_INT_CRRDY1 				(1 << (ADC_CTLINTENSET_CRRDY_Pos+1))
```

## Summary

Identifies ADC global interrupt status

## Description

These macros identifies ADC global interrupt status and is passed as argument into the
ADC Global event handler to let application identify the ADC global interrupt for which the
callback is being given.
