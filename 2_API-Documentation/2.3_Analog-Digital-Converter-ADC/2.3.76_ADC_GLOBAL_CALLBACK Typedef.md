# 2.3.76 ADC_GLOBAL_CALLBACK Typedef

## C

```C
typedef void (*ADC_GLOBAL_CALLBACK)(ADC_GLOBAL_INT status, uintptr_t context);
```

## Summary

Defines the function pointer data type and function signature for the adc peripheral global callback function.


## Description

This data type defines the function pointer and function signature for the adc peripheral
global callback function. The adc peripheral will call back the client's
function with this signature when any ADC global event occurs.
