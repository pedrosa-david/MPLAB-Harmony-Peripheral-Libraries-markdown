# 2.3.70 ADC_CORE_INT_CMPHIT Macro

## C

```C
#define ADC_CORE_INT_CMPHIT					(ADC_INTFLAG_CMPHIT_Msk)
```

## Summary

Identifies ADC core interrupt status

## Description

These macros identifies ADC core interrupt status and is passed as argument into the
ADC Core event handler to let application identify the ADC core interrupt for which the
callback is being given.
