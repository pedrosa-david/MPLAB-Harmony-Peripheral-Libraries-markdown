# 2.82.1 PORT_Initialize Function

## C

```C
void PORT_Initialize(void)
```

## Summary

Initializes the PORT Library.


## Description

This function initializes all ports and pins as configured in the MCC Pin Manager.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
PORT_Initialize();
```

## Remarks

The function should be called once before calling any other PORTS PLIB functions.
