# 2.110.1 SUPC_Initialize Function

## C

```C
void SUPC_Initialize( void );
```

## Summary

Initializes the SUPC peripheral.

## Description

This function initializes the SUPC peripheral of the device with the values configured in
        MCC GUI.

## Precondition

MCC GUI should be configured with the right values.

## Parameters

None.

## Returns

None.

## Example

```C
SUPC_Initialize();
```

## Remarks

This function should only be called once during system initialization before any other SUPC function is called.
