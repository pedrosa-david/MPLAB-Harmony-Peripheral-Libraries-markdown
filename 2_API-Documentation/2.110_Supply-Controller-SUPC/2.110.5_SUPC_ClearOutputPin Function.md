# 2.110.5 SUPC_ClearOutputPin Function

## C

```C
void SUPC_ClearOutputPin( SUPC_OUTPIN pin );
```

## Summary

Clears a specific output pin (OUTx) to logic LOW.

## Description

There are two pins controlled by the SUPC. This API helps to drive
a logic LOW on a given OUTx pin.

## Precondition

None.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| pin | Identifies the output pin to be cleared |

| Param | Description |
| --- | --- |
| pin | Identifies the output pin to be cleared |

## Returns

None.

## Example

```C
SUPC_ClearOutputPin( SUPC_OUTPIN_OUT0 );
```
