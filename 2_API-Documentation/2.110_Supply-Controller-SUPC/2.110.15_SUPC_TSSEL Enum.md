# 2.110.15 SUPC_TSSEL Enum

## C

```C
typedef enum
{
    SUPC_TSSEL_PTAT = 0,
    SUPC_TSSEL_CTAT = 1
}SUPC_TSSEL;
```

## Summary

Identifies the temperature sensor channels of SUPC peripheral.

## Description

There are two temperature sensor channels controlled by SUPC.
This enum type can be used to specify the channel when calling
the APIs which controls temperature sensors channels.
eg. SUPC_SelectTempSenorChannel( SUPC_TSSEL_PTAT );
