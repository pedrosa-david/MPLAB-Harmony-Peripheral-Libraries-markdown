# 2.50.1 HEFC_Initialize Function

## C

```C
void HEFC_Initialize( void )
```

## Summary

Initializes given instance of the HEFC peripheral.


## Description

This function initializes the given instance of the HEFC peripheral as configured by the
        user from within the MCC.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
HEFC_Initialize();
```

## Remarks

This function should be called before calling any other HEFC library function.
