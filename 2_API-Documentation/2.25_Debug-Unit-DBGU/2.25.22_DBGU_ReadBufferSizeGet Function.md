# 2.25.22 DBGU_ReadBufferSizeGet Function

## C

```C
/* Ring buffer mode */

size_t DBGU_ReadBufferSizeGet(void)
```

## Summary

Returns the size of the receive ring buffer


## Description

This function returns the size of the receive ring buffer, which is same as the size of the
        receive ring buffer configured in MCC.


## Precondition

DBGU_Initialize must have been called for the associated DBGU instance.


## Parameters

None


## Returns

The API returns the size of the receive ring buffer.


## Example

```C
size_t rxBufferSize;

rxBufferSize = DBGU_ReadBufferSizeGet();
```

## Remarks

None
