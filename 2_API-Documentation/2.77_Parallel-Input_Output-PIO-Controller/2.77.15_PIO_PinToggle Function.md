# 2.77.15 PIO_PinToggle Function

## C

```C
void PIO_PinToggle(PIO_PIN pin)
```

## Summary

Toggles the selected pin.


## Description

This function toggles/inverts the value on the selected I/O line/pin.


## Precondition

PIO_Initialize() must have been called.


## Parameters
