# 2.77.20 PIO_PinInterruptEnable Function

## C

```C
void PIO_PinInterruptEnable(PIO_PIN pin)
```

## Summary

Enables IO interrupt on selected IO pin.

## Description

This function enables interrupt on selected IO pin.

## Precondition

Corresponding pin must be configured in interrupt mode in MCC Pin Manager. PIO_Initialize()
        must have been called.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| pin | One of the IO pins from the enum PIO_PIN |

| Param | Description |
| --- | --- |
| pin | One of the IO pins from the enum PIO_PIN |

## Returns

None.

## Example

```C
PIO_PinInterruptEnable(PIO_PIN_PB3);
```

None.
