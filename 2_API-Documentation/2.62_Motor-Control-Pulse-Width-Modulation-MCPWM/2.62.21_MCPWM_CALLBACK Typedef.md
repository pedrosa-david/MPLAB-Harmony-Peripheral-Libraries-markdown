# 2.62.21 MCPWM_CALLBACK Typedef

## C

```C
typedef void (*MCPWM_CALLBACK)(uintptr_t context )
```

## Summary

Defines the data type and function signature for the MCPWM peripheral callback function for primary event and secondary event

## Description

This data type defines the function signature for the MCPWM peripheral
callback function. The library will call back the client's
function with this signature from the interrupt context.
