# 2.17 CMSIS

CMSIS is a standard set of interfaces provided by ARM to access the features of the core
            peripherals in their devices (For eg: NVIC or GIC , Systick or Generic Timer etc.). This
            component is auto activated by MCC for any ARM device that supports it.
