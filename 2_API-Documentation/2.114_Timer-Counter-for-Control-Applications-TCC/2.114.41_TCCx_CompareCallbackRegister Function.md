# 2.114.41 TCCx_CompareCallbackRegister Function

## C

```C
/* x = TCC instance number */
void TCCx_CompareCallbackRegister( TCCx_CALLBACK callback, uintptr_t context );
```

## Summary

Registers the function to be called from interrupt.

## Description

This function registers the callback function to be called from interrupt.

## Precondition

TCCx_CompareInitialize() must have been called first.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| callback | callback function pointer |
| context | Allows the caller to provide a context value (usually a pointer to the callers context for multi-instance clients) |

| Param | Description |
| --- | --- |
| callback | callback function pointer |
| context | Allows the caller to provide a context value (usually a pointer to the callers context for multi-instance clients) |

## Returns

None.

## Example

```C
void TCC_Callback_Fn( uintptr_t context );

TCC0_CompareInitialize();
TCC0_CompareCallbackRegister(TCC_Callback_Fn, NULL);
```

## Remarks

Context value can be set to NULL if not required. To disable callback function, pass NULL for the callback parameter.
