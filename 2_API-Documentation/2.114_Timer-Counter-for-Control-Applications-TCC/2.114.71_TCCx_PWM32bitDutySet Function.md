# 2.114.71 TCCx_PWM32bitDutySet Function

## C

```C
/* x = TCC instance number */
void TCCx_PWM32bitDutySet (TCCx_CHANNEL_NUM channel, uint32_t duty);
```

## Summary

Sets the duty value of a given TCC channel.


## Description

This function writes the compare value. Every channel of TCC instance has its own
            compare register. When counter matches compare value interrupt can be generated. This
            function writes to the double buffered register. Actual update happens on period match
            or zero match.


## Precondition

TCCx_PWMInitialize function must have been called first for the given channel.


## Parameters
