# 2.1.7 AC_SwapInputs Function

## C

```C
void AC_SwapInputs (AC_CHANNEL channel)
```

## Summary

Swap inputs of a comparator.

## Description

This function swaps inputs of a comparator. This allows the user to measure
or compensate for the comparator input offset voltage.

## Precondition

AC_Initialize must have been called for the associated AC instance.
