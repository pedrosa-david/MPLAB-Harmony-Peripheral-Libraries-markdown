# 2.1.1 AC_Initialize Function

## C

```C
void AC_Initialize (void);
```

## Summary

Initializes AC module of the device

## Description

This function initializes AC module of the device with the values configured in MCC GUI.
        Once the peripheral is initialized, Status API can be used to get the comparison status.

## Precondition

None.

## Parameters

None.

## Returns

None.

## Example

```C
AC_Initialize();
```

## Remarks

This function must be called only once and before any other AC function is called. This is taken care in initialization.c.
