# 2.10.12 CCPx_Timer16bitPeriodGet Function

## C

```C
/* x = CCP instance number */

uint16_t CCPx_Timer16bitPeriodGet( void )
```

## Summary

Reads the period value of given timer.

## Description

This function reads the value of period.

## Precondition

CCPx_TimerInitialize() function must have been called first.

## Parameters

None.

## Returns

uint16_t - The timer's period value.

## Example

```C
uint16_t period = 0;
CCP1_TimerInitialize();
period = CCP1_Timer16bitPeriodGet();
```

## Remarks

The caller must know the number of significant bytes of timer. Period value is right-aligned.
