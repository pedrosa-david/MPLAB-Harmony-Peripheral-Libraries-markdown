# 2.14.24 CLK_UPLLInitMiddle Function

## C

```C
void CLK_UPLLInitMiddle(void)
```

## Summary

Controls UPLL Voltage Regulator.

## Description

This function turn on UPLL voltage regulator.

## Precondition

Clock module should be configured using MCC Clock Manager and code should be generated, and
        CLK_UPLLInitStart() must be called before this function call.

## Parameters

None.

## Returns

None.

## Example

```C
//Example 3: Do not alter the configuration bit settings
CLK_UPLLInitStart();
// Insert Delay function here
CLK_UPLLInitMiddle();
```
