# 2.14.19 CLK_PLLConfig Function

## C

```C
void CLK_PLLConfig(PLL_ID pllID, uint8_t clkSrc, uint32_t mul, uint32_t fracr, 
uint8_t output0Div, uint8_t output1Div);
```

## Summary

Configures PLL parameters


## Description

This function configures given PLL clock parameters run-time.


## Precondition

None.


## Parameters

| Parameter | Description |
|-----------|-------------|
| pllID | PLL ID |
| clkSrc | PLL clock source |
| mul | Multiplier factor value for PLL |
| fracr | Fractional loop divider setting |
| output0Div | Divider for PMC output 0 |
