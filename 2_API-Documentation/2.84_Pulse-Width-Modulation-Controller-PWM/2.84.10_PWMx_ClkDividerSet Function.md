# 2.84.10 PWMx_ClkDividerSet Function

## C

## Summary

Selects the divider value for the clock source for the PWM peripheral


## Description

Selects the divider value for the clock source for the PWM peripheral. The Clock
                source is then divided by the value of divVal + 1.


## Precondition

None
