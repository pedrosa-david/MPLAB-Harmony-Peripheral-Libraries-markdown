# 2.27 Device family pack

Device family pack is the component that allows the harmony applications to access device
            specific information (device header files, linker scripts, metadata etc.). This is a
            required component for all the projects and will be activated automatically by the MCC
            upon creation of a harmony project. This component do not have any configurable
            options.
