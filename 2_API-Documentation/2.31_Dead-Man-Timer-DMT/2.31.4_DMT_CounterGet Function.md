# 2.31.4 DMT_CounterGet Function

## C

```C
uint32_t DMT_CounterGet( void )
```

## Summary

Returns the DMT current counter value.


## Description

This function returns the current DMT counter value. The value is the number of
instructions counted since the count was last cleared.


## Precondition

DMT must be enabled using DMT_Enable().


## Parameters

None.


## Returns

The current counter value.


## Example

```C
uint32_t value = 0;

DMT_Enable();
value = DMT_CounterGet();
```

## Remarks

None.
