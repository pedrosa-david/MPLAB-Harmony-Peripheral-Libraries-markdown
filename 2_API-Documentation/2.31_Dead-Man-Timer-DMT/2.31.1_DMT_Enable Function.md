# 2.31.1 DMT_Enable Function

## C

```C
void DMT_Enable( void );
```

## Summary

Enables the DMT peripheral.


## Description

This function enables the DMT peripheral. Calling this function will cause
the DMT to start counting up to the configured timeout count value.


## Precondition

Should be generated only if FDMTEN fuse bit is OFF in MCC device configuration.


## Parameters

None.


## Returns

None.


## Example

```C
DMT_Enable();
```

## Remarks

None.
