# 2.44.2 FCW_Read Function

## Summary

Reads length number of bytes from a given address in FLASH memory.


## Description

Reads length number of bytes from a given address in FLASH memory into the user buffer.


## Precondition

None


## Parameters

|-----------|-------------|
