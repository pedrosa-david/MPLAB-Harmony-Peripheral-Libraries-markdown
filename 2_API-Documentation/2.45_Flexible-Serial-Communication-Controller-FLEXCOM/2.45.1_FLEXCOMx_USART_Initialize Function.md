# 2.45.1 FLEXCOMx_USART_Initialize Function

## C

```C
/* x = FLEXCOM instance number */

/* Blocking, non-blocking and ring buffer mode */

void FLEXCOMx_USART_Initialize( void )
```

## Summary

Initializes given instance of the FLEXCOM USART peripheral.


## Description

This function initializes the given instance of the FLEXCOM USART peripheral as configured
        by the user from within the MCC.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
FLEXCOM0_USART_Initialize();
```

## Remarks

Stops the FLEXCOM USART if it was already running and reinitializes it.
