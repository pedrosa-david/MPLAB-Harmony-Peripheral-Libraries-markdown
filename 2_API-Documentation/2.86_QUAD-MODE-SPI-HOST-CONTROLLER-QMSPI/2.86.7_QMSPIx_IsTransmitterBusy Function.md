# 2.86.7 QMSPIx_IsTransmitterBusy Function

## C

```C
// x - Instance of the QMSPI peripheral

bool QMSPIx_IsTransmitterBusy (void):
```

## Summary

Returns transfer status of QMSPI peripheral.

## Description

This function returns transfer status of last successful Write or Read  request on QMSPI
        module.

## Precondition

None.

## Parameters

None.

## Returns

Returns the current status of transfer happening on QMSPI

true: Transfer is still in progress

false: Transfer is completed

- true: Transfer is still in progress
- false: Transfer is completed

## Example

```C
if (QMSPI0_IsTransmitterBusy() == false)
{
    //Data Transfer is complete, do something else.
}
```
