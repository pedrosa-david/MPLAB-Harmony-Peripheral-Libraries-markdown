# 2.29.5 DMA_ChannelDisable Function

## C

```C
void DMA_ChannelDisable ( DMA_CHANNEL channel )
```

## Summary

The function disables the specified DMA channel.


## Description

The function disables the specified DMA channel. Once disabled, the channel
will ignore triggers and will not transfer data till the next time a
DMA_ChannelTransfer function is called. If there is a transfer already in
progress, this will suspended.


## Precondition

DMA should have been initialized by calling DMA_Initialize.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| channel | The DMA channel that needs to be disabled |


| Param | Description |
| --- | --- |
| channel | The DMA channel that needs to be disabled |


## Returns

None.


## Example

```C
// Disable the channel.
DMA_ChannelDisable (DMA_CHANNEL_0);
```

None.
