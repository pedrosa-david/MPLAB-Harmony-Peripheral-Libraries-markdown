# 2.29.6 DMA_ChannelEnable Function

## C

```C
void DMA_ChannelEnable ( DMA_CHANNEL channel )
```

## Summary

The function enables the specified DMA channel.


## Description

The function enables the specified DMA channel. Once enabled, DMA will initiate
a block transfer when the selected trigger is received


## Precondition

DMA should have been initialized by calling DMA_Initialize.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| channel | The DMA channel that needs to be disabled |


| Param | Description |
| --- | --- |
| channel | The DMA channel that needs to be disabled |


## Returns

None.


## Example

```C
// Enable the channel.
DMA_ChannelEnable (DMA_CHANNEL_0);
```

None.
