## Using The Library

The AIC peripheral library initializes interrupt controller as configured by the user in
        the MCC. User can launch the AIC configurator using the "Tools" drop down in MCC menu bar.
        Using the AIC configurator, user can enable interrupt, configure priority, interrupt type
        and interrupt vector name.
