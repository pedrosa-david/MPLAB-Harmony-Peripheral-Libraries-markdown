# 2.22.1 DAC_Initialize Function

## C

```C
void DAC_Initialize (void);
```

## Summary

Initializes DAC module of the device


## Description

This function initializes DAC module of the device with the values configured in MCC GUI.
        Once the peripheral is initialized, APIs can be used to convert the data.


## Precondition

MCC GUI should be configured with the right values.
