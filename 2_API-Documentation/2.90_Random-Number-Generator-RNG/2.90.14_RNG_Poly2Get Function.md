# 2.90.14 RNG_Poly2Get Function

## C

```C
uint32_t RNG_Poly2Get (void);
```

## Summary

Returns the value of the RNGPOLY2 register.

## Description

The polynomial equation for PRNG is set via the RNGPOLYx registers. Use
this function to read the polynomial.

## Precondition

None.

## Parameters

None.

## Returns

Value of the RNGPOLY2 register.

## Example

uint32_t poly2 = 0;
poly2 = RNG_Poly2Get();
