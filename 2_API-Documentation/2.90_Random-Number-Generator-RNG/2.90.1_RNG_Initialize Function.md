# 2.90.1 RNG_Initialize Function

## C

```C
void RNG_Initialize (void);
```

## Summary

Initializes RNG module of the device

## Description

This function initializes RNG module of the device with the values configured in MCC
        GUI.

## Precondition

None.

## Parameters

None.

## Returns

None.

## Example

```C
RNG_Initialize();
```

## Remarks

This function must be called only once and before any other RNG function is called. This is taken care in initialization.c.
