# 2.2.1 ACC_Initialize Function

## C

```C
void ACC_Initialize (void);
```

## Summary

Initializes ACC module of the device

## Description

This function initializes ACC module of the device with the values configured in MCC GUI.
        Once the peripheral is initialized, Status API can be used to get the comparison status.

## Precondition

MCC GUI should be configured with the right values.

## Parameters

None.

## Returns

None.

## Example

```C
ACC_Initialize ();
```

## Remarks

This function must be called only once and before any other ACC function is called.
