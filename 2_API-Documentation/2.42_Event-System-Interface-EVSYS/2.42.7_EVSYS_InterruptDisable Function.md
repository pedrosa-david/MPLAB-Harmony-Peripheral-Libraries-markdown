# 2.42.7 EVSYS_InterruptDisable Function

## C

```C
void EVSYS_InterruptDisable( EVSYS_CHANNEL channel, EVSYS_INT_MASK interruptMask )
```

## Summary

Disables EVSYS interrupt

## Description

This function disables the specified EVSYS interrupt.

## Precondition

EVSYS module should be initialized with the required configuration parameters from the MCC
        GUI in the EVSYS_Initialize() function

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| channel | Channel for which the interrupt needs to be disabled |
| interrupt | Interrupt to be Disabled |

| Param | Description |
| --- | --- |
| channel | Channel for which the interrupt needs to be disabled |
| interrupt | Interrupt to be Disabled |

## Returns

None

## Example

```C
// Disable Event System channel 2 Event Detection interrupt
EVSYS_InterruptDisable(EVSYS_CHANNEL_2, EVSYS_INT_EVENT_DETECT);
```

## Remarks

Interrupts configuration will be generated in EVSYS_Initialize() function as per user
        settings in MCC. The EVSYS_InterruptEnable and EVSYS_InterruptDisable API should be used to
        enable and disable interrupt at run time.
