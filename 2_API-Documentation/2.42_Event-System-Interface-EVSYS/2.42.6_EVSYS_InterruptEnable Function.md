# 2.42.6 EVSYS_InterruptEnable Function

## C

```C
void EVSYS_InterruptEnable( EVSYS_CHANNEL channel, EVSYS_INT_MASK interruptMask )
```

## Summary

Enables EVSYS interrupt


## Description

This function enables the specified EVSYS interrupt.


## Precondition

EVSYS module should be initialized with the required configuration parameters from the MCC
        GUI in the EVSYS_Initialize() function


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| channel | Channel for which the interrupt needs to be enabled |
| interrupt | Interrupt to be enabled |


| Param | Description |
| --- | --- |
| channel | Channel for which the interrupt needs to be enabled |
| interrupt | Interrupt to be enabled |


## Returns

None


## Example

```C
// Enable Event System channel 2 Event Detection interrupt
EVSYS_InterruptEnable(EVSYS_CHANNEL_2, EVSYS_INT_EVENT_DETECT);
```

## Remarks

Interrupts configuration will be generated in EVSYS_Initialize() function as per user
        settings in MCC. The EVSYS_InterruptEnable and EVSYS_InterruptDisable API should be used to
        enable and disable interrupt at run time.
