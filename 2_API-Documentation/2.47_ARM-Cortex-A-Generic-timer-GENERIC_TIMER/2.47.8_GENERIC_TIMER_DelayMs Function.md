# 2.47.8 GENERIC_TIMER_DelayMs Function

## C

```C
void GENERIC_TIMER_DelayMs(uint32_t delay_ms);
```

## Summary

Delays processing for x milliseconds.

## Description

Delays execution by using the generic timer to determine when given number of
milliseconds has expired.

## Precondition

Generic timer is configured, running with interrupt enabled.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| delay_ms | number of milliseconds to delay |

| --- | --- |
| delay_ms | number of milliseconds to delay |
