# 2.61.37 MCAN_ERROR_LEC_BIT1 Macro

## C

```C
#define MCAN_ERROR_LEC_BIT1 0x4U
```

## Summary

MCAN Error LEC_BIT1


## Description

During transmission of a message (with the exception of the arbitration field), the
device tried to send a recessive level (bit of logical value ‘1’), but the monitored bus
value was dominant.
