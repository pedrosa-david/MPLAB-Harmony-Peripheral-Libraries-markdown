# 2.61.51 MCAN_ERROR_DLEC_NO_CHANGE Macro

## C

```C
#define MCAN_ERROR_DLEC_NO_CHANGE 0x700U
```

## Summary

MCAN Error DLEC_NO_CHANGE


## Description

Data Phase - Any read access to the Protocol Status Register re-initializes the LEC to ‘7’. When
the LEC shows value ‘7’, no CAN bus event was detected since the last processor
read access to the Protocol Status Register.

None.
