# 2.61.23 MCANx_SleepModeEnter Function

## C

```C
void MCANx_SleepModeEnter(void) // x - Instance of the MCAN peripheral
```

## Summary

Puts the MCAN Peripheral in sleep mode (clock stop request).


## Precondition

MCANx_Initialize and MCANx_MessageRAMConfigSet must have been called for the associated MCAN instance.
