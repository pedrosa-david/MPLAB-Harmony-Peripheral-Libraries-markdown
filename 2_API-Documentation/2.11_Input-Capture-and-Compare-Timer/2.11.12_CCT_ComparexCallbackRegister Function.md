# 2.11.12 CCT_ComparexCallbackRegister Function

## C

```C
/* x = Compare channel number */

void CCT_ComparexCallbackRegister( CCT_CALLBACK callback, uintptr_t context )
```

## Summary

Allows application to register a callback with for the CCT compare channel

## Description

This function sets the pointer to a client/application function to be called "back"
                when the free running timer value matches the compare value. It also passes a
                context value (usually a pointer to a context structure) that is passed into the
                function when it is called. The specified callback function will be called from the
                peripheral interrupt context. The callback should be registered before starting the
                free running timer.

## Precondition

CCT_Initialize() function must have been called first.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| callback | A pointer to a function with a calling signature
                                defined by the CCT_CALLBACK data type. Setting this to NULL disables
                                the callback feature. |
| context | A value (usually a pointer) which is passed (unused)
                                into the function identified by the callback parameter |

## Example

```C

}
```
