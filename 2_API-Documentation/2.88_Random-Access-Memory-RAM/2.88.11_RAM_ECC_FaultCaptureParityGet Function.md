# 2.88.11 RAM_ECC_FaultCaptureParityGet

## C

```C
uint8_t RAM_ECC_FaultCaptureParityGet(void)
```

## Summary

Returns the parity of the captured ECC fault.

## Description

This function returns the parity value associated with the most recent ECC fault detected
        in the RAM.

## Precondition

None

## Parameters

None

## Returns

parity value of  ECC fault.

## Example

```C
uint8_t faultParity;

// Get the parity value of the captured ECC fault
faultParity = RAM_ECC_FaultCaptureParityGet();
```
