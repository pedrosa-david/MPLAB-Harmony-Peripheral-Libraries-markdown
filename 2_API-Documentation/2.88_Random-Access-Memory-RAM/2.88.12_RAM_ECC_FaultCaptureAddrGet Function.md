# 2.88.12 RAM_ECC_FaultCaptureAddrGet Function

## C

```C
uint32_t RAM_ECC_FaultCaptureAddrGet(void)
```

## Summary

Returns the address of the captured ECC fault.


## Description

This function returns the address where the last ECC fault was detected in the RAM, as
        stored in the MCRAMC_ERRCADR register.


## Precondition

None


## Parameters

None


## Returns

returns the fault address


## Example

```C
uint32_t faultAddress;

// Get the address of the captured ECC fault
faultAddress = RAM_ECC_FaultCaptureAddrGet();
```
