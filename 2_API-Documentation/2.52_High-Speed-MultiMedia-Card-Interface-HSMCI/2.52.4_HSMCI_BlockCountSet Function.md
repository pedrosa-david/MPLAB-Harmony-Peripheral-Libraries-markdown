# 2.52.4 HSMCI_BlockCountSet Function

## C

```C
void HSMCI_BlockCountSet ( uint16_t numBlocks )
```

## Summary

Sets the number of blocks to transfer


## Description

Sets the number of blocks to transfer for a multi-block transfer. For example,
the block count must be set to the appropriate value before issuing the
multi-block read (CMD 18) or write (CMD 25) commands. For single blcok read
(CMD 17) or write (CMD24) commands, the block count must be set to 1.


## Precondition

HSMCI_Initialize() must have been called first.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| numBlocks | Number of blocks to transfer |


| Param | Description |
| --- | --- |
| numBlocks | Number of blocks to transfer |


## Returns

None.


## Example

```C
HSMCI_BlockCountSet(1);
```
