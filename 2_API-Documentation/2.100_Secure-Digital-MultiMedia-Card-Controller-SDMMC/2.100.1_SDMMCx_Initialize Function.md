# 2.100.1 SDMMCx_Initialize Function

## C

```C
/* x = SDMMC instance number */

void SDMMCx_Initialize( void )
```

## Summary

Initializes the SDMMC peripheral and the internal data structures used by the peripheral library.


## Description

This function initializes the SDMMC peripheral. The SDMMC peripheral is
initialized in 1 bit mode and the SDMMC clock is set to 400 kHz. The clock
mode used is the programmable clock mode. This function also initializes
the internal data structures used by the peripheral library.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
SDMMC1_Initialize();
```
