# 2.71.10 OCMP_CALLBACK Typedef

## C

```C
typedef void (*OCMP_CALLBACK) (uintptr_t context);
```

## Summary

Defines the function pointer data type and function signature for the OCMP callback function.

## Description

This data type defines the function pointer and function signature for the
callback function. The library will call back the client's
function with this signature from the interrupt routine.
