# 2.71.2 OCMPx_Enable Function

## C

```C
/* x = OCMP instance number */

void OCMPx_Enable (void)
```

## Summary

Enable function for the OCMPx peripheral

## Description

This function enables the OCMPx peripheral. This function starts the waveform generation
based on the mode.

## Precondition

OCMPx_Initialize() function must have been called first.

## Parameters

None.

## Returns

None.

## Example

```C
OCMP1_Initialize();
OCMP1_Enable();
```

## Remarks

Selected Timer source module must be enabled for functioning of OCMP peripheral.
