# 2.81.5 PMP_MasterReceive Function

## C

```C
uint32_t PMP_MasterReceive( void )
```

## Summary

Receives the data in Master mode.

## Description

This function receives the data. The flow of data is from the slave to the
master.

## Precondition

PMP should have been initialized by calling PMP_Initialize and configured for Master mode.

## Parameters

None.

## Returns

uint32_t - Data received

## Example

```C
uint32_t data;

PMP_Initialize();
PMP_AddressSet(0x1);

if(!PMP_PortIsBusy())
{
    data = PMP_MasterReceive();
}
```
