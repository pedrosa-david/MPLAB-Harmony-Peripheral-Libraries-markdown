# 2.83.4 POWER_ReleaseGPIO Function

## C

```C
void POWER_ReleaseGPIO( void );
```

## Summary

Release GPIO pins

## Description

This function release GPIO pins after wakeup from deep sleep.

## Precondition

None.

## Parameters

None.

## Returns

None.

## Example

```C
POWER_ReleaseGPIO();
```

## Remarks

This function is only available for the devices which has deep sleep controller. MCC will
        generate this function only for the selected devices accordingly. Check device datasheet for
        more information.
