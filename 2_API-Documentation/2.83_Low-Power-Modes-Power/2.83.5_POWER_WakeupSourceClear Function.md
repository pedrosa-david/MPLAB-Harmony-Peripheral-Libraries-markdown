# 2.83.5 POWER_WakeupSourceClear Function

## C

```C
void POWER_WakeupSourceClear( POWER_WAKEUP_SOURCE wakeupSource )
```

## Summary

Clears the wakeup source


## Description

This function clears the wakeup (from deep sleep) source information from
the register so that next time updated wakeup source can be found.


## Precondition

None.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| wakeupSource | wakeup source to be cleared |


| Param | Description |
| --- | --- |
| wakeupSource | wakeup source to be cleared |


## Returns

None.


## Example

```C
POWER_WakeupSourceClear(POWER_WAKEUP_SOURCE_DSINT0);
```

## Remarks

This function is only available for the devices which has deep sleep controller. MCC will
        generate this function only for the selected devices accordingly. Check device datasheet for
        more information.
