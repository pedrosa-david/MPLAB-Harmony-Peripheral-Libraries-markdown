# 2.83.11 POWER_DS_RTCC_PowerEnable Function

## C

```C
void POWER_DS_RTCC_PowerEnable(void);
```

## Summary

Enables the RTCC module in the Deep Sleep mode.


## Description

Enables the RTCC module in the Deep Sleep mode.


## Precondition

To enable RTCC function, RTCC module level registers must also be programmed.


## Parameters

None.


## Returns

None.


## Example

POWER_DS_RTCC_PowerEnable()


## Remarks

This function is only available for the devices which has deep sleep controller. MCC will
        generate this function only for the selected devices accordingly. Check device datasheet for
        more information.
