# 2.83.7 POWER_DSGPR_Read Function

## C

```C
uint32_t POWER_DSGPR_Read(POWER_DSGPR gprNumb);
```

## Summary

Reads saved data

## Description

This function reads the data which was saved during deep sleep mode.

## Precondition

None.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| gprNumb | selects the DSGPR register which has to be read |

| Param | Description |
| --- | --- |
| gprNumb | selects the DSGPR register which has to be read |

## Returns

Returns the value read

## Example

```C
uint32_t savedData;
savedData = POWER_DSGPR_Read(POWER_DSGPR0);
```

## Remarks

This function is only available for the devices which has deep sleep controller. MCC will
        generate this function only for the selected devices accordingly. Check device datasheet for
        more information.
