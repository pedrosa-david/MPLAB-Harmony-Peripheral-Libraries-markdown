# 2.53.3 HTMx_PeriodSet Function

## C

```C
/* x = HTM timer instance number */

void HTMx_PeriodSet(uint16_t period)
```

## Summary

Sets the time period and starts the HTM timer


## Description

Sets the pre-load register value and resets the down counter to start counting down
                from this programmed value


## Precondition

HTMx_Initialize() function must have been called first.
