# 2.40.1 EIC_Initialize Function

## C

```C
void EIC_Initialize (void);
```

## Summary

Initializes given instance of EIC peripheral.

## Description

This function initializes given instance of EIC peripheral of the device with the values
        configured in MCC GUI.

## Precondition

MCC GUI should be configured with the right values.

## Parameters

None.

## Returns

None.

## Example

```C
EIC_Initialize();
```

## Remarks

This function should only be called once during system initialization before any other EIC function is called.
