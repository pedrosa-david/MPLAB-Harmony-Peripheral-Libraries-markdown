# 2.23.1 DAC_CTRL_Initialize Function

## C

```C
void DAC_CTRL_Initialize(void);
```

## Summary

Initializes DAC_CTRL module of the device.

## Description

This function initializes DAC_CTRL module of the device with the values configured in
                MCC GUI. Once the peripheral is initialized, APIs can be used to convert the
                data.

## Precondition

MCC GUI should be configured with the right values.

## Parameters

None.

## Returns

None.

## Example

```C
DAC_CTRL_Initialize();
```

None.
