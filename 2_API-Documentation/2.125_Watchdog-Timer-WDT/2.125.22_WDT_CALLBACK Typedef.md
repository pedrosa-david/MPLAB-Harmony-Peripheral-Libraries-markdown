# 2.125.22 WDT_CALLBACK Typedef

## C

```C
typedef void (*WDT_CALLBACK)(uintptr_t context);
```

## Summary

Defines the data type and function signature for the WDT peripheral callback
                function.


## Description

This data type defines the function signature for the WDT peripheral callback
                function. The WDT peripheral will call back the client's function with this
                signature when the WDT timer expires.


## Precondition

None


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| context | A value (usually a pointer) which is passed (unused)
