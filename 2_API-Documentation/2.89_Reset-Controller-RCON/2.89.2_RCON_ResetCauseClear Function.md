# 2.89.2 RCON_ResetCauseClear Function

## C

```C
void RCON_ResetCauseClear( RCON_RESET_CAUSE cause )
```

## Summary

Clears the particular reset cause status bit.

## Description

This function clears the particular reset bit in the RCON register. Multiple
reasons for a reset can be ORed together and given as an input parameter to
clear them simultaneously.

## Precondition

None.

## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| cause | Reset status needs to be clear |

| Param | Description |
| --- | --- |
| cause | Reset status needs to be clear |

## Returns

None.

## Example

```C
RCON_ResetCauseClear( RCON_RESET_CAUSE_POR | RCON_RESET_CAUSE_BOR );
```
