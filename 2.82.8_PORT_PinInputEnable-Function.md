# 2.82.8 PORT_PinInputEnable Function

## C

```C
void PORT_PinInputEnable(PORT_PIN pin)
```

## Summary

Configures the selected IO pin as input.


## Description

This function configures the selected IO pin as input. This function override the MCC input
        output pin settings.


## Precondition

The PORT_Initialize() function should have been called.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| pin | One of the IO pins from the enum PORT_PIN. |


| Param | Description |
| --- | --- |
| pin | One of the IO pins from the enum PORT_PIN. |


## Returns

None.


## Example

```C
PORT_PinInputEnable(PORT_PIN_PB03);
```
