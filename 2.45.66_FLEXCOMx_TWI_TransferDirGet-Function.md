# 2.45.66 FLEXCOMx_TWI_TransferDirGet Function

## C

```C
/* x = FLEXCOM instance number */

/* TWI slave mode */
FLEXCOM_TWI_SLAVE_TRANSFER_DIR FLEXCOMx_TWI_TransferDirGet(void)
```

## Summary

Returns the TWI transfer direction.


## Description

This function returns the TWI transfer direction.


## Precondition

FLEXCOMx_TWI_Initialize must have been called for the associated FLEXCOM TWI instance.


## Parameters

None.


## Returns

FLEXCOM_TWI_SLAVE_TRANSFER_DIR_WRITE - TWI master is writing data to TWI slave


FLEXCOM_TWI_SLAVE_TRANSFER_DIR_READ - TWI master is reading data from TWI slave


## Example

```C
FLEXCOM_TWI_SLAVE_TRANSFER_DIR transferDir;
transferDir = FLEXCOM0_TWI_TransferDirGet();
```
