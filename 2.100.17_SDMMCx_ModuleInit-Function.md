# 2.100.17 SDMMCx_ModuleInit Function

## C

```C
/* x = SDMMC instance number */

void SDMMCx_ModuleInit ( void )
```

## Summary

Initializes the SDMMC peripheral.


## Description

This function initializes the SDMMC peripheral. The SDMMC peripheral is
initialized in 1 bit mode and the SDMMC clock is set to 400 kHz. This function
may be called at run time to re-initialize the peripheral to the initial
state.
