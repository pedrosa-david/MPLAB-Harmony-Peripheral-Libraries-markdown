# 2.3.44 ADC_FIFORead Function

## C

```C
uint32_t ADC_FIFORead(void)
```

## Summary

## Description

Returns a single ADC conversion value from the ADC FIFO


## Precondition

ADCx_Initialize() function must have been called first for the associated instance.


## Parameters

None


## Returns

uint32_t - ADC result value


## Example

```C

}
```
