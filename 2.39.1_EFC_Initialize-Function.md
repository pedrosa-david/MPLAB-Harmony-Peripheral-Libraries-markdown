# 2.39.1 EFC_Initialize Function

## C

```C
void EFC_Initialize( void )
```

## Summary

Initializes given instance of the EFC peripheral.


## Description

This function initializes the given instance of the EFC peripheral as configured by the
        user from within the MCC.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
EFC_Initialize();
```

## Remarks

This function should be called before calling any other EFC library function.
