# 2.125.17 WDT_WindowEnable Function

## C

```C
void WDT_WindowEnable( void );
```

## Summary

Enables the WDT window mode.


## Description

This function enables the WDT window mode.


## Preconditions

This API is generated to enable the Window mode in firmware if the window mode is disabled
        by setting WINDIS fuse bit to OFF/NORMAL in MCC device configuration.


## Parameters

None.


## Returns

None.


## Example

```C
WDT_WindowEnable();
```
