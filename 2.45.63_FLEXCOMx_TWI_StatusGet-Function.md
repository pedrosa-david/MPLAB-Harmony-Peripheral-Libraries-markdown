# 2.45.63 FLEXCOMx_TWI_StatusGet Function

## C

```C
/* x = FLEXCOM instance number */

/* TWI slave with interrupt disabled */

FLEXCOM_TWI_SLAVE_STATUS_FLAG FLEXCOMx_TWI_StatusGet(void)
```

## Summary

Returns the TWI hardware status flags.


## Description

This function returns the TWI hardware status flags


## Precondition

FLEXCOMx_TWI_Initialize must have been called for the associated FLEXCOM TWI instance.


## Parameters

None.


## Returns

FLEXCOM_TWI_SLAVE_STATUS_FLAG - enum identifying the status bits set. One or more status bits may be set.


## Example

```C
FLEXCOM_TWI_SLAVE_STATUS_FLAG twi_status;

twi_status = FLEXCOM0_TWI_StatusGet();
```
