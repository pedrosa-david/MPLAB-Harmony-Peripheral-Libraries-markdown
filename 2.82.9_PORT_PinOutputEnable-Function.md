# 2.82.9 PORT_PinOutputEnable Function

## C

```C
void PORT_PinOutputEnable(PORT_PIN pin)
```

## Summary

Enables selected IO pin as output.


## Description

This function enables selected IO pin as output. Calling this function will override the
        MCC input output pin configuration.


## Precondition

The PORT_Initialize() function should have been called.


## Parameters

### Parameters

| Parameter | Description |
|-----------|-------------|
| pin | One of the IO pins from the enum PORT_PIN. |


| Param | Description |
| --- | --- |
| pin | One of the IO pins from the enum PORT_PIN. |


## Returns

None.


## Example

```C
PORT_PinOutputEnable(PORT_PIN_PB03);
```

None.
