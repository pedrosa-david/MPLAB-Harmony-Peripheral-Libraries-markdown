# 2.103.33 SERCOMx_ISO7816_Cold_Reset

## C

```C
/* x = SERCOM instance number */

void SERCOMx_ISO7816_Cold_Reset( void )
```

## Summary

This API provides the cold reset functions to card.


## Description

This API allows the application to cold reset the device. RST in low state, VCC
                powered, I/O in reception mode in the interface device, CLK provided with a suitable
                and stable clock signal, the card is ready for a cold reset. The cold reset results
                from maintaining RST at state low for at least 400 clock cycles after the clock
                signal is applied to CLK. The answer on I/O shall begin between 400 and 40 000 clock
                cycles after the RST signal is high.


## Precondition

SERCOMx_ISO7816_Card_Detect function must be called.
