# 2.1.5 AC_Start Function

## C

```C
void AC_Start (AC_CHANNEL channel);
```

## Summary

Triggers a comparator to start comparison


## Description

This function triggers a comparator to start comparison, when it is
configured in single-shot mode.


## Precondition

AC_Initialize must have been called for the associated AC instance.
