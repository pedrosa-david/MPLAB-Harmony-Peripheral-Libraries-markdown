# 2.21.1 CVR_Initialize Function

## C

```C
void CVR_Initialize (void);
```

## Summary

Initializes CVR module of the device


## Description

This function initializes CVR module of the device with the values configured in MCC
        GUI.


## Precondition

None.


## Parameters

None.


## Returns

None.


## Example

```C
CVR_Initialize();
```

## Remarks

This function must be called only once and before any other CVR function is called. This is taken care in initialization.c.
