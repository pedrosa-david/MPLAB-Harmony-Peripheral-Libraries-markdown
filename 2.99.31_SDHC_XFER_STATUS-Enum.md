# 2.99.31 SDHC_XFER_STATUS Enum

## C

```C
typedef enum
{
    // Command transfer completed
    SDHC_XFER_STATUS_CMD_COMPLETED = 0x01,
    // Data transfer completed
    SDHC_XFER_STATUS_DATA_COMPLETED = 0x02,
    // Card insertion event
    SDHC_XFER_STATUS_CARD_INSERTED = 0x04,
    // Card removal event
    SDHC_XFER_STATUS_CARD_REMOVED = 0x08
    
}SDHC_XFER_STATUS;
```

## Summary

The enumeration lists SDHC transfer status events


## Description

The enumeration is passed by the SDHC PLIB in the client event handler to
allow the client to identify if the event handler is called on completion of
command or data or for a card insertion/removal event.
