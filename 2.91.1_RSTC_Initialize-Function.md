# 2.91.1 RSTC_Initialize Function

## C

```C
void RSTC_Initialize (void)
```

## Summary

Initializes RSTC module with the user configuration


## Description

This function initializes RSTC module of the device with the values configured in MCC GUI.
        Once the peripheral is initialized, RSTC APIs can be used to generate reset or to get the
        cause of reset.


## Precondition

MCC GUI should be configured with the right values.


## Parameters

None.


## Returns

None.


## Example

```C
RSTC_Initialize();
```

## Remarks

None.
