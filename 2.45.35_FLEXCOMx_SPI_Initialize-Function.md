# 2.45.35 FLEXCOMx_SPI_Initialize Function

## C

```C
/* x = FLEXCOM instance number */

/* SPI master and slave mode */

void FLEXCOMx_SPI_Initialize (void)
```

## Summary

Initializes FLEXCOM SPI module of the device


## Description

This function initializes FLEXCOM SPI module of the device with the values configured in
        MCC GUI. Once the peripheral is initialized, transfer APIs can be used to transfer the
        data.


## Precondition

MCC GUI should be configured with the correct values.


## Parameters

None


## Returns

None


## Example

```C
FLEXCOM0_SPI_Initialize();
```

## Remarks

This function must be called only once and before any other FLEXCOM SPI function is called
